    Notes

    How anomalies are defined

    Baseline average is computed over non-null kWh values. An anomaly is flagged when: kWh ≥ (1 + threshold) × average.

    Threshold is fixed at 20% in the dashboard UI (configurable via API query param if needed).

    Tip: include a region column in your CSV to enable region filtering (e.g. North, South).
